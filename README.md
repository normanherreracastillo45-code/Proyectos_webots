# Proyectos_webots
Simulaciones Robóticas en Webots 🤖
Este repositorio documenta el desarrollo y la implementación de controladores robóticos utilizando el simulador Webots. Los proyectos exploran conceptos prácticos de Inteligencia Artificial, visión computacional y control de hardware virtual, diseñados como parte de mi formación en Ingeniería en Sistemas Computacionales.
